## Definition Format

Each entry follows a consistent structure:

```markdown
### Term Name
*Sources (N): Source Name; Source Name*

Primary synthesized definition — the clearest, most complete explanation drawn from all contributing sources.

**Additional context from other sources:**

> Supplementary definition from another authoritative source.
> Another perspective adding useful nuance.
```

Definitions are **not** shortened or summarized. We preserve full explanatory context from every source.
