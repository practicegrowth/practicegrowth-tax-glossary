## Format

Each comparison follows a consistent structure:

1. **The Short Answer** — one-paragraph summary for quick reference
2. **Side-by-Side** — decision matrix in table format
3. **Decision Framework** — when to choose each option, with income-level guidance
4. **Common Mistakes** — misconceptions that trigger IRS issues or missed savings
5. **Related Terms** — cross-references to the main glossary
6. **When to Call a Professional** — soft CTA positioning tax professionals as essential
